## Tujuan

Tugas ini bertujuan untuk memahami penggunaan percabangan
`if-elif-else` dan validasi input dalam bahasa pemrograman Python.

## Daftar Program

1. `01_predikat_nilai.py` — Menentukan predikat nilai.
2. `02_kategori_bilangan.py` — Mengelompokkan bilangan.
3. `03_validasi_rentang.py` — Memvalidasi dan mengklasifikasikan sudut.
4. `04_validasi_tipe.py` — Memeriksa tipe dan rentang input.
5. `05_klasifikasi_segitiga_sudut.py` — Mengklasifikasikan segitiga berdasarkan sudut.
6. `validasi_klasifikasi_nilai.py` — Memvalidasi dan mengklasifikasikan nilai mahasiswa.

## Cara Menjalankan Program

Jalankan perintah berikut di Terminal VS Code:

```bash

python latihan/02_kategori_bilangan.py
python latihan/03_validasi_rentang.py
python latihan/04_validasi_tipe.py
```
